# E-8 重复性与方差（p10-var）

> 本次花费 **¥10.04**（12 次调用 / 100,462 输入 / 62,735 输出），累计 **¥281.89**。
> 切片 `p1-subsample/S4`（26 文件 / 12 条缺陷），批大小 6，deepseek-chat，
> 全部 0 丢批 / 0 失败 / `stop_reason=max_rounds_reached`。

## 1. 为什么这是最后一块必须补的板

此前所有对照都是**单次运行**，而 E-10 已经证明 ±1 条会改变百分比的解读。
更要紧的是：我们主张的差异量级就是 1~2 条（`2 胜 3 平 0 负`、均值 +0.6）。
**如果重复运行的波动也有 ±1~2 条，那些差异就全部落进噪声里。** 这一节直接测波动。

## 2. 结果

| 臂 | 配置 | 本轮 | 历史同配置 | n | 均值 | 范围 | 样本标准差 |
| --- | --- | --- | --- | ---: | ---: | --- | ---: |
| 3 Agent 分散 | 3 读者 / 每人 9 文件 / 批 6 | 9, 11, 10 | 10（`p4-chat`）、9（`p5-e3`） | 5 | **9.80** | 9–11 | **0.84** |
| 单 Agent 分批 | 1 读者读全 26 / 批 6 | 10, 10, 9 | 10（`p6-single`） | 4 | **9.75** | 9–10 | **0.50** |
| 差 | | | | | **+0.05** | | |

**分散与单 Agent 的均值差是 0.05 条，而单臂自身标准差就有 0.5~0.84 条。**
换句话说，两者在这套语料上**无法区分**。

## 3. 这个结果推翻了什么

### 3.1 `2 胜 3 平 0 负、均值 +0.6` 不能当作优势证据

五个切片上的逐片差值是 `0, 0, +1, 0, +2`。若单臂标准差 ≈ 0.8，那么 `+2` 完全在
单次运行的正常抖动范围内（本轮实测同一配置在 S4 上就是 9→11，跨度 2 条）。
**结论应改写为「无差异」，而不是「有轻微倾向性优势」。**

### 3.2 「多 Agent 不比单 Agent 差」这句话是稳的

0 负这一点在 8 次运行里没有被推翻；能主张的只是**不更差**。

### 3.3 唯一稳的优势仍然只有速度

并发比顺序快 2.91 倍是**结构性**的（3 个读者并行发请求），不依赖质量指标的噪声，
也不受召回口径影响。**这是目前唯一站得住的「更优」。**

## 4. 与 E-10 的口径结论合并后的最终表述

| 主张 | 能否主张 | 依据 |
| --- | --- | --- |
| 分散读 > 集中读（同预算） | ✅ 可以 | 覆盖是结构性的（集中臂只读到 9/26 文件），差值 4~6 倍于噪声 |
| 读全 > 分散 > 集中（臂间排序） | ✅ 可以 | 五档容差 + 多种难度下排序一致 |
| 多 Agent 分散 > 单 Agent 分批 | ❌ **不可以** | 均值差 0.05，噪声 0.5~0.84 |
| 共享不如隔离（召回层面） | ❌ 不可以说 | 5 切片 3 胜 2 平；只可说机制层（K\*、冗余率）5/5 |
| 并发快 2.91 倍 | ✅ 可以 | 结构性差异，非统计推断 |
| 绝对召回率 82% | ⚠ 只能带口径 | 精确行口径为 38% |
| 精确率 | ⚠ 已测，46%（CI 28%~65%） | `p9-precision/RESULT.md` |

## 5. 限制

- 只在 S4 一个切片上估的方差；S1/S3/S6 的缺陷构成不同，方差可能不同。
- 语音模型采样温度与后端调度都不可控，重复运行不是严格的同分布抽样。
- n=4~5，标准差本身的估计误差很大（相对误差约 35%）。
- 召回仍是 25 行容差口径。
