# 预算台账

> 单价基准：**¥0.16 / 次调用**（源自 2026-10-28~29 的实测账单：44 次调用约 ¥7）

## 记录规则

1. **每次运行结束立刻记账**，不要事后补——事后补必然漏。
2. 调用次数从 `metrics.json` 的 `llm_calls` 取，不要靠估算。
3. token 同时记（`prompt_tokens` / `completion_tokens`），便于反算单价变化。
