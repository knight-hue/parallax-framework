# 单 Agent 基线（五切片）

对照：**3 Agent 分散**（`blind_no_coverage` + `equal_exposure`，每人读 N/3） vs **单 Agent 分批**
（`readers=1`，一人顺序读完 N 个文件）。批大小均锁为 6，模型 deepseek-chat。

| 切片 | 单 Agent 分批 | 3 Agent 分散 | 差 |
| --- | ---: | ---: | ---: |
| S1 | 8/9 | 8/9 | 0 |
| S2 | 8/10 | 8/10 | 0 |
| S3 | 4/10 | 5/10 | **+1** |
| S4 | 10/12 | 10/12 | 0 |
| S6 | 4/10 | 6/10 | **+2** |

- **分散 2 胜 3 平 0 负**，均值 +0.6。
- 符号检验（2/5 胜）p≈0.25，**不显著**。
- 两臂总读取量相同（各 N 个文件），差别只在「是否切成三个独立视角」。

## 结论

1. **多 Agent 不输给单 Agent**（5 片 0 负），并有轻微倾向性优势，但**不足以主张「显著更好」**。
2. 因此多智能体的可用论据是组合式的：**同等质量（0 负）+ 快 2.91 倍**（见 `tools/latency_report.py`）。
3. 单 Agent 一次读全部 26 文件只有 6/12（S4），说明**瓶颈在输出容量而非上下文**——
   真正起作用的是「有界分批」，不是「多个 Agent」。

## 限制

- n=5 切片，召回为邻近匹配口径；采样子语料，绝对召回不可与全量运行比较。
- 单 Agent 分批与 3 Agent 分散在本实现里都无跨 Agent 交流，唯一差别是并行度与分区。
