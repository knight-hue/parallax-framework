## 2. Java 平台网关 — 约 2.5 分钟

```powershell
cd "$R\gateway"

# 2.1 打包（离线；产物 ~89 MB fat jar）
mvn.cmd -o -B -DskipTests package
#   期望：BUILD SUCCESS，约 28 秒；target\parallax-gateway-0.1.0.jar

# 2.2 测试：116 项
mvn.cmd -o -B test
#   期望：Tests run: 116, Failures: 0, Errors: 0, Skipped: 0；约 1 分 58 秒
```

> **不需要 MySQL / Redis / RabbitMQ 在跑。** 集成测试自带替身，实测在全部中间件关闭的情况下 116 项全过。
>
> 日志里会出现几行 `ERROR ... Exception Processing [ErrorPage[...]]` —— 那是**故意触发错误路径**的测试产生的，不是失败。判定只看最后的 `Tests run` 汇总行。
